Connecting Slack to AetherFlow lets you surface workflow activity directly inside the channels your team already monitors. Whether you want to alert a channel when a critical process completes, post a daily digest of automated task results, or remind teammates of upcoming deadlines, the Slack integration gives AetherFlow the ability to act inside your workspace on your behalf. Follow the steps below to authorize the integration and start building.

## Connect Slack to AetherFlow

<Steps>
  <Step title="Open the Integrations catalog">
    In the AetherFlow sidebar, click **Integrations**, then search for **Slack** and select its tile.
  </Step>
  <Step title="Click Connect">
    On the Slack integration page, click **Connect**. AetherFlow will redirect you to Slack's OAuth authorization screen.
  </Step>
  <Step title="Review and approve permissions">
    Slack will display the list of permissions AetherFlow is requesting — such as the ability to post messages and read channel lists. Select the workspace you want to connect from the dropdown in the top-right corner of the Slack screen, then click **Allow**.
  </Step>
  <Step title="Configure the connection">
    After authorization, you'll return to AetherFlow. Give the connection a descriptive name (for example, *Team Workspace – Slack*) so it's easy to identify when building workflows.
  </Step>
  <Step title="Test the connection">
    Click **Send Test Message**, choose a channel, and confirm the test message appears in Slack. A successful test means your integration is ready to use in any workflow.
  </Step>
</Steps>

<Note>
  You can connect multiple Slack workspaces by repeating the steps above and authorizing a different workspace each time. Each connection appears separately in your Connected Apps list.
</Note>

## Common Workflow Examples

Once Slack is connected, you can reference it in any workflow you describe to AetherFlow. Here are the most popular ways teams use the Slack integration.

### Send a Channel Message

Trigger a plain-text or rich-formatted message to any public or private channel your connected bot has access to. Use this to announce completed automations, relay incoming form submissions, or broadcast pipeline stage changes.

**Example prompt:** *"When a new lead is added to our CRM, send a message to the #sales-alerts channel with the lead's name and company."*

### Post Notifications

Post structured notifications when a workflow reaches a specific condition — an error threshold, an approval decision, or a time-based trigger. Notifications keep your team informed without requiring anyone to log in and check a dashboard.

**Example prompt:** *"Every weekday at 9 am, post a summary of open support tickets to #customer-success."*

### Create Reminders

Use Slack's reminder feature to schedule a reminder for yourself or a teammate at a future time — directly from a workflow. This is useful for surfacing time-sensitive tasks generated by automated processes.

**Example prompt:** *"When a contract is sent for signature, create a Slack reminder for me in 48 hours if it hasn't been signed yet."*

<Tip>
  Use AetherFlow's plain-language workflow builder to describe exactly what you want. You don't need to configure Slack API parameters manually — AetherFlow translates your description into the correct integration actions automatically.
</Tip>

## Troubleshooting

<Accordion title="AetherFlow can't find the channel I want to post to">
  The Slack bot must be a member of any private channel before it can post there. Open the channel in Slack, click the channel name at the top to open its settings, go to **Integrations → Add apps**, and add the AetherFlow bot. Public channels are accessible by default once the integration is authorized.
</Accordion>

<Accordion title="Messages are sending but formatting looks wrong">
  AetherFlow supports Slack's Block Kit formatting for rich messages. If your message contains markdown that isn't rendering as expected, check that the workflow action is set to **Rich Text / Block Kit** rather than plain text. You can update this in the workflow action settings panel.
</Accordion>

<Accordion title="The test message succeeded but live workflow messages aren't appearing">
  First, confirm the workflow is active — navigate to **Workflows**, find your workflow, and check that its status shows **Active**. Next, check the workflow's execution log for any error events. Common causes include a channel name change in Slack (update the channel reference in the workflow action) or a token expiration (disconnect and reconnect the Slack integration to refresh the token).
</Accordion>

<Accordion title="I authorized the wrong Slack workspace">
  Go to **Integrations → Connected Apps**, find the Slack connection, and click **Disconnect**. Then return to the Slack integration page and click **Connect** again, this time selecting the correct workspace from the dropdown on the Slack authorization screen.
</Accordion>

<Accordion title="My Slack connection shows as inactive or expired">
  Slack OAuth tokens can expire if permissions are revoked from the Slack side. To restore the connection, go to **Integrations → Connected Apps**, disconnect the affected Slack connection, and reauthorize it. If your Slack workspace enforces token expiration policies, check with your Slack admin to ensure AetherFlow's app is approved.
</Accordion>
